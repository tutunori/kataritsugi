# UI 概要（簡易ワイヤー）

ステータス: **方針ドラフト**  
目的: 実装前に画面の骨格と主要コピーを揃える。ビジュアルデザインは別途。

## 1. 情報アーキテクチャ

```text
タブ構成（案）
├─ ホーム
├─ インタビュー
├─ 記録（セッション／文字起こし）
├─ 自叙伝
└─ その他（設定・プラン・家族・対話）
```

プレミアムの対話は「その他」または自叙伝横の入口。未契約時はロック表示。

## 4. 管理画面（簡易）

運用者向け（Web）。詳細は `docs/ops/admin.md`。

| 画面 | 内容 |
| --- | --- |
| ダッシュボード | アカウント数、プラン分布、ジョブ失敗率 |
| アカウント詳細 | plan 変更、ストレージ使用量 |
| 削除依頼キュー | 対応状況 |
| 同意文バージョン | 文書の版管理 |

## 5. アクセシビリティとトーン

- 敬体で温かみのある短い文言
- エラーは責めず、次の一手を示す（「再送信」「下書きに保存しました」）
- プレミアム導線は恐怖訴求ではなく、いまの記録を活かす提案
