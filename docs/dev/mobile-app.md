# モバイルアプリ方針

ステータス: **方針ドラフト**

## 1. 役割

モバイルは語り継ぎの **主クライアント**。

| できること | 内容 |
| --- | --- |
| 録音 | インタビュー音声の高品質録音、一時保存 |
| 同期 | 回線復帰後の自動アップロード |
| 確認 | 文字起こしの閲覧・修正 |
| 進行 | ガイド質問の表示、セッション管理 |
| 成果物 | 自叙伝の閲覧・簡易編集、（premium）対話 |

初期ターゲット OS は **Android / iOS 両対応を目指す**（実装順は後で決定。片側先行可）。

## 2. UX 原則（高齢話者への配慮）

操作の主は 40〜50 代でも、画面は話者の近くで使われる。

- 文字は大きく、1 画面 1 アクション
- 録音中は赤く大きいインジケータ。誤停止を防ぐ確認
- ガイド質問は読み上げ（TTS）オプション
- 「専門用語」を避け、同意文は段階表示
- 暗い場所・室内でも使えるコントラスト

## 3. 主要画面（アプリ）

詳細ワイヤーは `docs/design/ui-overview.md`。

1. ログイン / 登録
2. ホーム（話者一覧・続きから）
3. 話者詳細（同意状態・進捗）
4. インタビュー（録音）
5. セッション一覧と文字起こし
6. 自叙伝
7. 設定・プラン・家族共有
8. （premium）対話チャット

## 4. 録音・文字起こしの技術方針

| 項目 | 方針 |
| --- | --- |
| 形式 | 端末標準の高品質フォーマット（例: AAC/m4a）。最終は実装時に確定 |
| チャンク | 長時間は分割アップロード可能な設計 |
| オフライン | ローカル DB にセッションとファイルパスを保持 |
| 文字起こし | サーバ側 ASR が基本。端末内 ASR は補助・将来検討 |
| バッテリー | バックグラウンド録音の OS 制約を明示（画面をつけたまま推奨など） |

## 5. 権限（OS）

- マイク必須
- 通知（文字起こし完了）推奨
- フォトライブラリは写真添付機能追加時

拒否時は設定導線を出し、録音開始をブロックする。

## 6. セキュリティ

- トークンは Secure Storage
- ローカル音声はアプリ私有領域。アンインストールで消える旨を説明
- スクリーンショット制限は必須にしない（家族が画面共有する場面があるため）

## 7. リリース方針（概要）

- 内部テスト → クローズド → ストア公開
- デモプランはストア審査の「アカウント削除」要件と整合させる
