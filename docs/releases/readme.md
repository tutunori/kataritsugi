# リリース記録

モバイル／API の版を公開したら、後から追えるよう控えを残す。

```text
docs/releases/<version>/
  RELEASE_NOTES.md
  （必要に応じて）API_COMPAT.md / STORE_NOTES.md
```

## 残すもの

- ユーザー向け変更点（録音、文字起こし、自叙伝、プラン）
- 破壊的変更・マイグレーション注意
- 最低サポートアプリバージョン（必要なら）

## 注意

このディレクトリは記録用。ストアや本番配信物の実体は別経路で管理する。

リリース作業の詳細 runbook は、実装が進んだら `docs/ops/` に追加する。
