# 管理画面の方針

ステータス: **方針ドラフト**

## 1. 位置づけ

一般ユーザー向け UI はモバイル。  
管理画面は **開発者・運用者専用** の Web UI。

```text
/api/v1/...   → モバイル向け API
/admin/...    → 運用者向け HTML
```

一般ユーザー認証とは分離する（AdminUser）。

## 2. 初期スコープ

| 機能 | 内容 |
| --- | --- |
| ログイン | AdminUser + session |
| ダッシュボード | アカウント数、プラン分布、失敗ジョブ |
| アカウント一覧 | 検索、plan の手動変更（Stripe 前） |
| 話者・セッション照会 | サポート時の状況確認（本文は最小限・要権限） |
| 削除依頼 | 受付〜完了のステータス |
| ドキュメント閲覧 | リポジトリ `docs/` の参照（任意） |

音声の任意ダウンロードは原則禁止または強い監査ログ付き。

## 3. ロール（案）

| ロール | 権限 |
| --- | --- |
| admin | 全操作 |
| support | 照会、削除依頼の進行。plan 変更は制限可 |
| readonly | ダッシュボードと集計のみ |

## 4. 運用で注意すること

- 文字起こし全文の画面表示はサポート目的に限定し、理由を残す
- プレミアムの対話ログも同様
- 本番 Basic 認証や IP 制限の併用を検討
