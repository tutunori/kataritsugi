## 3. 競合から見える市場の示唆（語り継ぎ向け）

| 示唆 | 内容 |
| --- | --- |
| 購買者は子世代が多い | Life Book・親の雑誌が明示。40〜50 代訴求と整合 |
| 「書く負担ゼロ」が共通価値 | ほぼ全社が代筆 or 聞き書き |
| 差別化は成果物フォーマット | 雑誌／文庫／上製本／小説／HP／PDF |
| 人的インタビューがコストの主因 | 22〜95 万円帯の多くがプロ聞き手前提 |
| デジタル単体は低価格帯が存在 | 良知 4.8 万円、Palette 5 万円〜 |
| 感情・回想・認知ケアの語り | 良知・Life Book が強い。福祉 AI 接続の布石になる |
| 写真は 10〜50 枚が実務レンジ | 少なくても成立する設計が必要 |

**空白（チャンス）:**  
「家族がスマホで複数回録音 → AI が文字起こし・構成・自叙伝化 → 人が最終品質だけ見る」  
という **AI 自動生成中心・少人数運用** は、上記 8 社の主戦場（プロ取材の手厚さ）とは異なる。

## 4. モデルケース：AI＋スタッフ 2 名で回すサービス体系

### 4.1 前提

| 項目 | 内容 |
| --- | --- |
| 人的資源 | 正味 **2 名**（役割は後述）。外部は印刷・決済・ASR/LLM API のみ |
| AI リソース | 一般的なクラウド ASR、LLM（文章構成・要約・章立て）、埋め込み検索、画像キャプション程度 |
| 原則 | **人が話を聞きに行かない**。録音・質問進行はアプリ＋家族。人は例外対応と最終検品 |
| 成果物の既定 | **デジタル自叙伝（画面＋PDF）** を標準。製本はパートナー印刷のオプション |
| 製品名（仮） | 語り継ぎ（既存 docs と同一） |

### 4.2 2 名の役割分担

| 役割 | 担当 | やること | やらないこと |
| --- | --- | --- | --- |
| **Ops / CS（1 名）** | 顧客成功・例外対応 | オンボーディング案内、同意トラブル、返金判断、クレーム、印刷発注窓口 | 通常のインタビュー実施、全文執筆 |
| **Editor / QA（1 名）** | 品質・プロンプト | 週次の生成品質レビュー、重大誤りの修正ルール整備、サンプル校正、プロンプト改善 | 全案件の一から執筆、訪問取材 |

繁忙時のみ、校正を時間課金の外部フリーランスに出す（常勤にしない）。

### 4.3 プラン体系（モデル）

既存の demo / free / paid / premium を、競合価格帯を見ながら **デジタル標準・製本オプション** で再定義する。

| プラン | 価格仮説（税別・月 or 買い切り） | ユーザーが得ること | 人の介在 |
| --- | --- | --- | --- |
| **demo** | 0 円・14 日 | 録音 1 回（〜15 分）＋文字起こし＋透かし付き短編 | なし（自動） |
| **free** | 0 円 | 月 2 セッション、簡易タイムライン、写真 20 枚まで | なし |
| **paid（スタンダード）** | 買い切り **49,800〜79,800 円** または 月額 **4,980 円**×年 | セッション計 6〜10、章立て自叙伝 PDF、写真 40、家族共有 | AI 自動。QA はサンプリングのみ |
| **premium** | 買い切り **148,000〜198,000 円** または 年額 | 無制限に近い録音、高品質再生成、対話プロファイル、優先処理、年表＋感情索引、製本チケット 1 | 最終 PDF の人による軽検品（チェックリスト）、印刷発注 |

**製本オプション（外注）:** Softcover 1〜5 冊 **+15,000〜40,000 円**、Hardcover **+40,000〜80,000 円** 程度を目安（印刷会社見積で確定）。

価格ポジションの意図:

- 親の雑誌・さくら文研（22〜33 万）より **低く**、デジタル完結で勝負
- Life Book 下位〜中位（9.8〜24.8 万）と隣接するが、**プロ訪問なし**で差別化
- my history（95 万）の上製本体験は取りに行かない（オプション止まり）

### 4.4 サービスメニュー（提供内容）

#### A. コア（全有料で共通・自動化）

1. ガイド付きインタビュー（アプリが質問を提示・読み上げ）
2. 音声アップロード → ASR 文字起こし
3. 感情／年代／人物タグの自動付与
4. 複数セッションの時系列統合
5. 章立て自叙伝ドラフトの LLM 生成
6. 家族による校正 UI（ハイライト修正 → 再生成）
7. PDF エクスポート

#### B. プレミアム付加（自動化＋軽い人検品）

1. ライフプロファイル（対話用構造化データ）
2. 「記録に基づく対話」チャット（根拠リンク必須）
3. 高品質レイアウト PDF（写真配置の自動組版）
4. 製本発注ワンクリック（外注）
5. 長期アーカイブ（オブジェクトストレージ）

#### C. 人が触る例外メニュー（有料・時間課金）

| メニュー | 内容 | 目安 |
| --- | --- | --- |
| リモート傾聴セッション | Ops/提携が Zoom で 60 分ファシリテート | +15,000 円／回 |
| 人による最終リライト | Editor が 1 章まで手直し | +20,000 円〜 |
| 写真スキャン代行 | 郵送セット（外注可） | 実費＋手数料 |

※モデルケースの **定常稼働では C を必須にしない**。転換用・クレーム回避用。

### 4.5 必要データの標準パッケージ（競合平均を AI 向けに再設計）

| データ | 推奨量（paid） | 収集方法 | 自動化 |
| --- | --- | --- | --- |
| 音声インタビュー | 合計 90〜180 分（3〜6 回×30 分） | 家族がアプリで録音 | ASR・話者分離 |
| 基本プロフィール | 生年、出身、学歴職歴の概略 | 初回フォーム（家族代行可） | 年表テンプレ生成 |
| 写真 | 20〜40 枚（キャプション短文） | スマホアルバムから選択 | 画像説明・年代推定の補助 |
| 感情メモ | 任意の短文 | セッション後の 3 タップ（楽しかった等） | タグ学習の教師信号 |
| 同意 | 自叙伝／共有／対話 | 電子同意 | バージョン管理 |

**書かせない。** さくら文研の 30 ページシート相当は、アプリの分岐質問＋音声で代替する。

### 4.6 自動生成パイプライン（人を介さない主経路）

```text
[録音] → [アップロード] → [ASR]
         → [セグメント整形] → [タグ付け LLM]
         → [エピソードカード化]
         →（セッション蓄積）
         → [自叙伝構成 LLM] → [事実チェック用抽出]
         → [家族校正ループ]
         → [PDF 組版]
         →（premium）[LifeProfile] → [対話 RAG]
```

人（Editor）は週次で:

- ランダム N 件のドラフトを読み、失敗パターンをプロンプト／評価セットに戻す
- 「幻覚・年代矛盾・過剰脚色」の自動検出ルールを更新する

### 4.7 オペレーション負荷の試算（2 名で回せるか）

仮定: paid 完成 1 件あたり **人の手作業 0.5〜1.0 時間**（案内メール自動、検品はサンプリング 10〜20%）。

| 月間完成件数 | Ops 負荷 | Editor 負荷 | 判定 |
| --- | --- | --- | --- |
| 20 件 | 低い | サンプリング中心で可 | 2 名で余裕 |
| 40 件 | 問い合わせ増 | プロンプト改善が本業 | 2 名で限界付近 |
| 80 件 | CS ツール必須 | 外部校正のスポット導入 | 自動化率をさらに上げる |

**設計目標:** 完成 1 件あたり人介入 **15 分以下**（アップセル・障害除く）。

### 4.8 競合対比での勝ち筋

| 軸 | 従来型（多くが該当） | 本モデル（語り継ぎ） |
| --- | --- | --- |
| 取材 | プロが訪問／複数回電話 | 家族＋アプリが複数回録音 |
| コスト構造 | 聞き手人件費が原価の大半 | API 従量＋ストレージが原価の中心 |
| 納期 | 1〜5 か月が多い | 初稿は数日〜2 週（校正待ち次第） |
| 成果物 | 紙の完成品が主 | デジタルが主、紙はオプション |
| 継続価値 | 納品で終わりがち | 追加録音・対話・更新（サブスク適合） |
| リスク | スケールしにくい | 品質のばらつき・同意・幻覚への対策が必須 |

### 4.9 品質・倫理のガードレール（少人数でも必須）

1. **脚色モードの明示** — 「記録要約」と「読み物脚色」を切替。デフォルトは要約寄り
2. **根拠リンク** — 各段落にセッション／時刻への参照
3. **家族校正を正式工程に入れる** — 人の Editor の代わりに家族を品質ゲートにする
4. **対話はオプトイン** — 競合にない二次利用は信頼設計が商品そのもの
5. **削除・エクスポート** — 低価格帯でも「データの主人は家族」を明示（購買者の不安対策）

### 4.10 段階的ローンチ（2 名前提）

| Phase | 内容 | 人の仕事 |
| --- | --- | --- |
| P1 | 録音・文字起こし・簡易まとめ PDF | 手動オンボ、重大バグ対応 |
| P2 | 章立て自叙伝・写真配置・paid 課金 | サンプリング QA、プロンプト固定 |
| P3 | premium 対話・製本オプション | 印刷パートナー連携、同意フロー強化 |
| P4 | 施設・B2B（ドリーマン事例に近い） | テンプレ横展開。人員増はここ以降検討 |
