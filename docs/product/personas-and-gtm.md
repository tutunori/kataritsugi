# ペルソナと Go-to-Market

ステータス: **方針ドラフト**

## 1. 二つの役割を分ける

語り継ぎでは **契約して支払う人** と **語る人** がしばしば別人である。

| 役割 | 典型 | 主な関心 |
| --- | --- | --- |
| 契約者（Buyer） | 40〜50 代の子・親族 | 親の記憶が消える不安、手間、価格、成果物の質 |
| 話者（Subject） | 主に 80 代の親・祖父母 | 話す負担、プライバシー、自分の人生がどう残るか |
| 閲覧者（Family） | 配偶者・兄弟・孫 | 読みやすさ、共有、追記の可否 |

MVP では契約者＝アプリ操作の主担当を想定する。話者は「話す」、契約者が「録る・確認する」。

## 2. 購買ターゲット（プライマリ）

### ペルソナ例: 佐藤さん（47）

- 両親は地方在住、父 82・母 79
- 年に数回の帰省。父の物忘れが増え、「今のうちに話を聞きたい」と感じている
- 自分でノートに書く時間は取れないが、スマホで録音なら手伝える
- 兄弟と共有したい。できれば読みやすい冊子や PDF が欲しい
- 価格感度は中程度。親への「何か残せる」体験に価値を感じる

### 訴求メッセージ（方向性）

- 「親の思い出を、話すだけで残せる」
- 「事実だけでなく、うれしかった・悲しかった気持ちも一緒に」
- 「忙しくても、数回のインタビューで一冊の物語に」
- 「失う前に、家族の記憶を構造化して残す」

不安の完全解消は約束しない。**今できる範囲で残す手段がある**こと自体が価値。

## 3. 話者ペルソナ（セカンダリ）

### ペルソナ例: 佐藤さんの父（82）

- 長い人生のエピソードはあるが、書くのは億劫
- 戦争直後・就職・結婚・子育ての話は得意。最近の出来事は曖昧になりやすい
- マイクを向けられると緊張する。家族が隣にいると話しやすい
- 「死後に AI で話す」は最初は抵抗があるかもしれない → 二次利用は後から説明・同意

インタビュー設計は、時系列の穴埋めだけでなく **感情の手がかり質問** を用意する。

## 4. 市場アプローチ

### 初期チャネル（仮説）

1. **子世代向けコンテンツ**: 介護・終活・家族史コミュニティ、SNS、Podcast
2. **帰省シーズン施策**: お盆・正月前の「親に聞く 10 の質問」無料ガイド
3. **地域・福祉連携の試験**: 地域包括・老人ホームのパイロット（プレミアム／B2B の芽）
4. **紹介**: 完成した自叙伝 PDF の一部共有からの口コミ

### ポジショニング

| 比較対象 | 語り継ぎの差 |
| --- | --- |
| ボイスメモ単体 | 整理・文字起こし・自叙伝化まで一気通貫 |
| 終活ノート | 書く負担が少なく、感情インタビューが中心 |
| 一般 AI チャット | 一次データ（本人の声と事実）に根ざす |
| 葬儀・遺影サービス | 「死後」ではなく「生きている今」から始める |

## 5. 倫理・信頼（購買の前提）

40〜50 代は「親のデータを企業がどう使うか」に敏感になりやすい。

必須の説明項目:

- 音声・テキストの保存場所と期間
- 誰がアクセスできるか（家族・運営・AI ベンダー）
- 二次利用（人格再現・福祉 AI）はオプトイン
- 解約・削除・エクスポートの権利
- 話者本人の同意取得フロー（契約者だけでは足りないケースの扱い）

## 6. 成功指標（初期）

| 指標 | 意味 |
| --- | --- |
| デモ完了率 | 初回インタビュー〜文字起こしまで到達した割合 |
| 有料転換率 | デモ／無料 → 有料／プレミアム |
| セッション継続率 | 2 回目以降のインタビュー実施率 |
| 自叙伝完成率 | ドラフト生成〜ユーザー確定まで |
| NPS / 「残せてよかった」定性 | 不安解消感の代理指標 |

詳細なプラン別上限と計測は `docs/product/plan-limits-and-metrics.md` を参照。
