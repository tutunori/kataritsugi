# プロダクトロードマップ

ステータス: **方針ドラフト**

## 方針サマリ

- 契約者はメール／パスワード（またはソーシャル）で登録し、話者プロファイルを作成する
- インタビュー音声はモバイルで録音し、サーバへアップロードする
- 文字起こし・タグ付け・自叙伝生成はサーバ側ジョブで処理する
- プランは **demo / free / paid / premium** の 4 段階
- 人格再現・福祉連携はプレミアム以降のオプトイン機能として後段に置く

## 決定事項（暫定）

1. **契約者と話者を分離できる** — 1 契約で複数話者（プラン上限あり）
2. **音声はオリジナルを保持** — 文字起こし後も再処理可能にする
3. **自叙伝はバージョン管理** — AI 生成と人手編集を履歴として残す
4. **二次利用は用途別同意** — 自叙伝作成同意と、対話 AI／研究利用同意は分ける
5. **デモは端末またはアカウント初回から期間制限** — 詳細はプラン文書

## プラン段階（概要）

| 段階 | 狙い | ざっくり権限 |
| --- | --- | --- |
| demo | 体験・転換 | 短い録音と文字起こしの試用、透かし付きドラフト |
| free | 習慣化・ライト利用 | 基本録音・文字起こし・簡易まとめ（上限厳しめ） |
| paid | 本格的な自叙伝作成 | 複数セッション、章立て自叙伝、家族共有 |
| premium | 高付加価値 | 対話プロファイル、高品質成果物、優先処理、長期保管 など |

詳細上限は `docs/product/plan-limits-and-metrics.md`。  
プレミアムの価値定義は `docs/product/premium-value.md`。

## 段階ロードマップ

### Phase 0 — 企画・基盤合意（現在）

- 本 docs 一式のレビューと用語統一
- 価格帯・上限の仮説設定
- 倫理・同意フローの骨格

### Phase 1 — MVP（録音〜文字起こし）

- ユーザー登録／ログイン
- 話者プロファイル作成
- モバイル録音・アップロード
- 文字起こしジョブと結果表示
- デモ／無料のゲート

完了の定義: 契約者が親の 1 セッションを録り、テキストを読める。

### Phase 2 — 自叙伝 MVP

- 感情・年代・イベントの基本タグ
- AI による章立てドラフト生成
- テキスト編集 UI
- 有料プラン導入（Checkout）

完了の定義: 3〜5 セッションから短い自叙伝 PDF／画面表示ができる。

### Phase 3 — 家族と品質

- 家族招待・閲覧／編集権限
- インタビューガイドの拡充
- 再文字起こし・話者分離の改善
- 管理画面でのユーザー・ストレージ監視

### Phase 4 — プレミアム

- 対話 AI 用ライフプロファイル生成（オプトイン）
- 高品質製本レイアウト／印刷連携（検討）
- 優先キュー・長期アーカイブ保証
- 福祉・研究向けデータエクスポート（厳格な同意）

### Phase 5 — 拡張（将来）

- 多言語、写真・年表とのマルチモーダル統合
- B2B（施設・自治体）向けテナント
- 音声合成による「声の読み上げ」（倫理審査前提）

## 認証・課金（方針）

| 項目 | 方針 |
| --- | --- |
| アプリ認証 | Bearer トークン（モバイル ↔ API） |
| 管理画面 | 別系統の Admin 認証 |
| プラン判定 | サーバが entitlements を返し、クライアントはキャッシュ可 |
| 決済 | Stripe 想定（後で確定）。初期は管理画面の手動 paid／premium 付与でも可 |
| 解約 | 期末まで権限維持など、後続で詳細決定 |

## 非目標（当面やらない）

- 最初から高精度の「故人との自由対話」を製品約束にしない
- 医療診断・認知機能の診断代替をうたわない
- 話者の同意なしの二次利用
