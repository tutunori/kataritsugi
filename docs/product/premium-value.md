# プレミアム版の付加価値

ステータス: **方針ドラフト**  
対象プラン: `premium`  
購買者イメージ: すでに記録を始めている、または「しっかり残したい」40〜50 代

## 1. プレミアムの役割

有料版（`paid`）が「きちんとした自叙伝を作る」標準だとすると、  
プレミアムは **残した記憶を、家族の暮らしと将来の対話にまで接続する** 層。

売り文句の方向性（例）:

- 「残す」から「受け継ぐ・対話する」へ
- 品質・保管・家族協働・将来利用まで含めたフルセット

不安を煽る表現は避ける。代替として「今ある声と物語を、より丁寧に残し活かす」。

## 2. 付加価値機能（優先度付き）

### P0 — プレミアムの核（初期リリース候補）

| 機能 | 内容 | 差別化ポイント |
| --- | --- | --- |
| ライフプロファイル | 事実・感情・価値観・言い回しを構造化した JSON/文書 | 後段の対話 AI・福祉 AI の入力になる |
| 対話 AI（オプトイン） | 自叙伝＋プロファイルに基づくチャット | 「読んで終わり」ではない継続価値 |
| 高品質自叙伝 | 編集者向けプロンプト、文体統一、年表付き PDF | ギフト・製本に耐える成果物 |
| 優先処理 | 文字起こし・生成キューの優先 | 帰省週末など時間制約への対応 |
| 拡張ストレージ・長期保管 | 大容量音声と長期アーカイブ方針の明示 | 「消えたら困る」不安への回答 |

### P1 — 強化

| 機能 | 内容 |
| --- | --- |
| 家族共同編集 | 章ごと担当、コメント、承認フロー |
| インタビュー設計プロ | 話者の年代・職歴に合わせた質問セット自動生成 |
| マルチモーダル添付 | 写真・手紙のスキャンと本文への挿入 |
| アクセス監査 | 誰がいつ聞いた／出したかのログ（家族向け透明性） |

### P2 — 要・倫理審査

| 機能 | 内容 | 注意 |
| --- | --- | --- |
| 声の読み上げ（TTS／類似音声） | 本人音声を学習した読み上げ | 同意・なりすましリスク・表示義務 |
| 死後モード | 契約者指定の公開範囲で対話を継続 | 相続・アカウント承継の法務 |
| 福祉 AI 連携 | ケアプラン補助等へのプロファイル提供 | 医療行為に該当しない範囲の明確化 |

## 3. 対話 AI（人格再現）の位置づけ

### できること（約束してよい範囲）

- 残されたテキストとタグに **根拠がある範囲** で、口調や価値観をまねた応答
- 「この話は記録にありません」と断る誠実さ
- 家族が質問し、記録を探索するインターフェース

### できないこと（約束しない）

- 本人と同一人格であることの保証
- 記録にない事実の断定
- 医療・法律・相続の助言の代替

UI 上は常に「記録に基づく再現であり、本人そのものではない」と表示する。

## 4. 同意モデル（プレミアム必須）

```text
[自叙伝作成の同意]  … paid 以上で必須に近い
[家族共有の同意]
[対話プロファイル生成の同意]  … premium
[声の類似利用の同意]          … 該当機能のみ
[福祉・研究連携の同意]        … 個別・撤回可能
```

話者が意思表示できる場合は話者同意を優先。  
代理同意が必要な場合のルールは法務レビュー後に確定する。

## 5. paid との境界（混乱防止）

| 体験 | paid | premium |
| --- | --- | --- |
| 章立て自叙伝 | ○ | ○（品質・更新頻度が上） |
| PDF 出力 | ○ | ○（年表・写真・製本レイアウト） |
| 家族共有 | ○（基本） | ○（高度な権限・監査） |
| 対話チャット | × | ○ |
| ライフプロファイル API/エクスポート | × | ○ |
| 優先キュー | × | ○ |

## 6. 成功の定義

- プレミアムユーザーの **対話利用率** と **自叙伝再訪率** が paid より高い
- 「親の話を残せてよかった」に加え、「家族で話が続いた」定性フィードバック
- オプトイン同意の理解度（誤解によるクレームが少ない）
