# プロダクトビジョン

ステータス: **方針ドラフト**（実装状況は `docs/product/roadmap.md` を参照）

## 語り継ぎとは

高齢の話者（主に 80 代）への口頭インタビューを繰り返し、  
**楽しかったこと・うれしかったこと・悲しかったこと**などの感情的な記憶と、  
**時系列的な事実**を丁寧に集め、AI の支援で自叙伝としてまとめるサービス。

単なる録音アプリではなく、**家族が「失う前に」記憶と知識を残せる基盤**であることが核になる。

| 項目 | 方針 |
| --- | --- |
| 主クライアント | モバイルアプリ（録音・文字起こし・確認） |
| サーバ | API（ユーザー・音声・テキスト・自叙伝・課金） |
| 話者（被インタビュー） | 主に 80 代前後の高齢親族 |
| 購買者（契約者） | 40〜50 代の子世代・親族 |
| 将来の活用 | 死後の人格再現対話、福祉 AI 向けプロファイリング |

## 解決したい不安

40〜50 代は、両親や親族の記憶・知恵・思い出が近い将来失われることへの不安を抱えやすい。  
語り継ぎは「全部を永遠に残す」のではなく、**今できる範囲で、感情と事実を構造化して残す**ことで、その不安を少しでも和らげる。

## ユーザ視点の価値

### 購買者（40〜50 代）

- 忙しくても、数回のインタビュー枠で親の話を残せる
- 音声→文字→章立て自叙伝までが一続きになる
- 家族で共有・追記でき、後から読み返せる
- 有料／プレミアムで品質と長期保管、対話活用まで広げられる

### 話者（主に 80 代）

- 「書く」負担が少なく、話すだけで進められる
- 感情を否定せず、楽しかった／悲しかった話も同じ重みで扱われる
- 自分の人生が「一冊の物語」として見える体験

## 想定する主要機能

- インタビューセッションの予約・進行ガイド
- モバイルでの音声録音とサーバへの安全なアップロード
- 音声の文字起こし（話者分離・タイムスタンプ付き）
- 感情タグ／ライフイベント／年代タグの付与
- AI による章立て自叙伝ドラフト生成と人手編集
- プラン別の保存量・生成回数・共有範囲の制御
- プレミアム: 対話 AI 用プロファイル、高品質製本 PDF、家族共同編集 など

## 目的の二層構造

| 層 | 目的 | 備考 |
| --- | --- | --- |
| 一次目的 | 感情的記憶と時系列事実の収集・自叙伝化 | MVP の中核。ユーザに約束する価値 |
| 二次目的 | 死後の人格再現、福祉 AI 対話のプロファイリング | 明示的オプトイン。倫理・同意・データ最小化が前提 |

二次目的は一次目的の質（インタビュー設計・感情ラベル・時系列整合）に依存する。  
**まず良い自叙伝データを作ること**が、将来の対話 AI 品質にも直結する。

## 開発の進め方

最初から人格再現や福祉連携まで広げず、  
**「録音 → 文字起こし → 編集 → 自叙伝」**の中核価値を固める。

成長イメージ:

1. モバイルで録音・アップロードできる
2. 文字起こしと基本タグ付けができる
3. AI 自叙伝ドラフトを生成・編集できる
4. デモ／無料／有料／プレミアムの課金ゲートを載せる
5. 家族共有と共同編集を追加する
6. プレミアムの対話プロファイルと高付加価値成果物を追加する
7. 福祉・研究用途向けの同意付きデータ連携を検討する

## 設計上の原則

- **同意と説明責任**: 録音・二次利用・人格再現は用途ごとに同意を取る
- **話者中心**: UI は大きく・手順は少なく。操作の主は購買者でもよいが、話者の負担を最小化
- **一次データの保全**: 音声・生テキストは加工後も残し、再生成可能にする
- **オフライン耐性**: 録音は端末に一時保存し、通信復帰後に同期する
- **プランで差をつける軸**: 機能ロックだけでなく、セッション数・保存容量・生成品質・成果物種で差を付ける
